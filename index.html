macOS · Swift · Early Access

Arc

A native macOS control surface for AI coding assistants. Arc puts live agent activity in the menu bar and notch, jumps you back to the right conversation, manages per-folder permissions, and lets connected agents collaborate through rooms, messages, tasks, handoffs and resource reservations.

  • Developer ID signed, Apple-notarised, Sparkle auto-updates
  • Ships a frozen Python MCP runtime and native helpers — no setup for users
  • Apple Silicon, macOS 14+

AI narration · Live

VoiceScript

An AI narration platform for creators. Paste a script and it becomes a manuscript — names, directions, tags and pauses parsed into tracked lines — then renders through GPU workers into studio-quality voiceovers. Design a voice from a description, cast it to a character, and re-render only the lines that changed.

  • Voice cloning, voice design and a reusable voice library
  • Smart chunking with change-aware selective re-render
  • Viseme worker for lip-synced character animation and FCPXML export
  • Billing, plans and usage quotas built into the workflow

Control plane · TypeScript

Orqara

A runtime-agnostic control plane for personal and team agent systems. The Kernel owns truth — tasks, approvals, queues, retries, lineage and verification — while adapters execute on Codex, OpenClaw, Hermes, direct LLM calls or shell. It keeps working even when a runtime breaks.

Security · MCP server

Orqara Guard

A standalone vulnerability analysis engine with a stdio MCP server and JSON CLI. Discovers manifests across a dozen ecosystems, matches with OSV-Scanner, de-duplicates GHSA/CVE aliases, and enriches with CISA KEV and FIRST EPSS — reporting failures honestly instead of treating them as safe.

Python · MCP

Arc MCP

A deliberately constrained MCP server that lets an assistant inspect only explicitly authorised folders — bounded reads, literal search, Git status/diff — with file and Git mutations gated per workspace and arbitrary execution behind an explicit Full Access switch.
